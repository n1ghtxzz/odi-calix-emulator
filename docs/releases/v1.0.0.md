# v1.0.0 — 2026-11-06

[English](#english) · [Русский](#русский)

## English

Calix/E7 compatibility release based on odi-oss, combining the preserved R6
service implementation and the R8.1 bilingual web interface. The MIB browser
has 106 classes. All native confirmations, modal dialogs and setup steps are
localized; logs and device data stay unchanged. Hardware DSCP command 52 is
still unsupported and unfinished DSCP changes are excluded.

Validation: full `make test TEST_JOBS=2` passed, including host boot/update
checks, protocol suites and Calix/E7 models. Browser tests use synthetic data
and passed 36 checks, including 30 confirmation variants. No live ONU writes
were performed. These tests do not claim hardware validation of a new line.

Public source contains no owner identity, credential, dump or line profile.
The owner image is distributed separately; it is not a public repository asset.

## Русский

Релиз совместимости Calix/E7 на основе odi-oss: рабочая сервисная часть R6
и двуязычный интерфейс R8.1. В MIB Browser 106 классов. Переведены все
подтверждения, встроенные окна и шаги мастера; журналы и данные устройства
сохранены в оригинале. Аппаратная команда DSCP 52 пока не поддерживается;
незавершённые изменения DSCP исключены.

Полный `make test TEST_JOBS=2` пройден: загрузка и обновление, протокол OMCI,
телефония, Calix/E7 и эмуляция ME. Пройдены 36 проверок браузера на
синтетических данных, включая 30 вариантов подтверждений. Записи на рабочую
ONU не выполнялись. Это не заменяет проверку конкретной оптической линии.

В публичных исходниках нет личных идентификаторов, паролей, дампов и профиля
линии. Персональный образ передаётся отдельно и не загружается в этот репозиторий.
